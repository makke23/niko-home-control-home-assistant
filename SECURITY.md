# Security policy

## Reporting a vulnerability

Do not publish passwords, Niko Hobby API tokens, Home Assistant access tokens,
diagnostic downloads, private IP addresses, or unredacted logs in a public
GitHub issue.

For a suspected security vulnerability, contact the maintainer privately
through the contact option on the GitHub profile of
[@makke23](https://github.com/makke23). Include only the minimum information
needed to reproduce the problem and remove credentials and personal data.

Ordinary bugs that contain no sensitive information can be reported through
the public issue tracker.
